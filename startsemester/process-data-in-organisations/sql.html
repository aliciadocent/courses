Wat is een database?

Een database is een georganiseerde verzameling gegevens die je met een DBMS (Database Management System) beheert, zoals MySQL. Je kunt het vergelijken met een Excel-bestand met meerdere tabbladen, maar dan strenger en krachtiger:

ExcelDatabase (MySQL)
StructuurVrij: je typt wat je wilt in elke celVast: elke kolom heeft een datatype (getal, tekst, datum)
HoeveelheidWordt traag bij honderdduizenden rijenMiljoenen rijen zijn geen probleem
SamenhangVerwijzingen tussen tabbladen gaan makkelijk stukRelaties worden bewaakt met sleutels (PK en FK)
Meerdere gebruikersLastig tegelijk te bewerkenGemaakt om door veel gebruikers en apps tegelijk te gebruiken
Vragen stellenFilters, formules, draaitabellenSQL-queries

SQL (Structured Query Language) is de taal waarmee je een relationele database aanstuurt: tabellen met rijen en kolommen die aan elkaar gekoppeld zijn. Er bestaan ook NoSQL-databases (zoals MongoDB) die gegevens als documenten opslaan, maar in dit topic werk je met SQL.

Stap 1: Docker Desktop installeren

We draaien MySQL in Docker. Docker zet software in een afgesloten "container", zodat je MySQL niet zelf hoeft te installeren en het op elke laptop hetzelfde werkt.

  1. Download Docker Desktop en installeer het.
    • Windows: laat de optie Use WSL 2 aangevinkt. Krijg je een melding over WSL? Open PowerShell als administrator, voer wsl --install (of wsl --update) uit en herstart je laptop.
    • Mac: kies de versie voor Apple Silicon (M1 t/m M4) of Intel. Welke je hebt, zie je via het Apple-menu → Over deze Mac.
  2. Start Docker Desktop en wacht tot het walvisje aangeeft dat Docker draait.
  3. Controleer in een terminal (Mac) of PowerShell (Windows) of het werkt: 
    docker run hello-world
    Zie je Hello from Docker!? Dan werkt het.

Stap 2: MySQL starten

Download eerst het MySQL-image. De tag lts staat voor long term support: de stabiele versie.

docker pull mysql:lts

Start daarna een container met de naam mysql-db en het wachtwoord welkom:

docker run --name mysql-db -e MYSQL_ROOT_PASSWORD=welkom -p 3306:3306 -d mysql:lts
OnderdeelBetekenis
--name mysql-dbDe naam van je container, zodat je hem later terugvindt.
-e MYSQL_ROOT_PASSWORD=welkomHet wachtwoord van de beheerder (root).
-p 3306:3306Maakt poort 3306 van de container bereikbaar op je laptop.
-dDraait de container op de achtergrond.

💡 Image en container

Een image is het recept, een container is het gerecht dat je ermee maakt. Je downloadt het image één keer en kunt er containers mee starten.

Handige commando's

CommandoWat het doet
docker psLaat zien welke containers draaien.
docker stop mysql-dbZet MySQL stil. Je gegevens blijven bewaard.
docker start mysql-dbStart MySQL weer op, bijvoorbeeld na een herstart van je laptop.
docker exec -it mysql-db mysql -u root -pOpent MySQL direct in de terminal.

⚠️ Let op

  • docker rm mysql-db verwijdert de container en alle databases erin.
  • Krijg je een foutmelding dat poort 3306 al in gebruik is (bijvoorbeeld door XAMPP)? Gebruik dan -p 3307:3306 en vul straks poort 3307 in.

Stap 4: De database van De Spaak laden

  1. Download spaak.sql.
  2. Open het bestand in je SQL-programma (in DBeaver: File → Open File, en kies je verbinding).
  3. Voer het hele script in één keer uit, niet regel voor regel. In DBeaver is dat Execute SQL Script (Alt+X, op de Mac ⌥+X). In Workbench is dat het bliksem-icoon.
  4. Ververs de lijst met databases. Je ziet nu de database spaak met zeven tabellen.

De tabellen volgen het datamodel van De Spaak: klant, fiets, monteur, reparatie, onderdeel, leverancier en de koppeltabel reparatie_onderdeel. Het script begint met DROP DATABASE IF EXISTS spaak, dus je kunt het opnieuw uitvoeren als je de database kapot hebt gemaakt.

USE spaak;
SHOW TABLES;

SQL als taal

SQL is een declaratieve taal: je beschrijft wat je wilt hebben, en de database bepaalt zelf hoe hij dat ophaalt. SQL-opdrachten vallen in twee groepen:

GroepOpdrachtenWaarvoor
DDL (Data Definition Language)CREATE, ALTER, DROPDe structuur bouwen: databases en tabellen.
DML (Data Manipulation Language)SELECT, INSERT, UPDATE, DELETEWerken met de gegevens zelf.

Spelregels:

  • Sluit elke opdracht af met een puntkomma ;.
  • Schrijf SQL-woorden in hoofdletters (SELECT, FROM). Dat is niet verplicht, maar wel afspraak, en het leest makkelijker.
  • Zet tekst en datums tussen enkele aanhalingstekens: 'e-bike', '2026-03-01'. Datums schrijf je als jjjj-mm-dd.
  • Gebruik geen spaties in namen van tabellen of kolommen, maar een underscore: datum_binnen.

De onderdelen van een SELECT hebben een vaste volgorde. Je mag onderdelen weglaten, maar niet omdraaien:

SELECT   kolommen          -- wat wil je zien?
FROM     tabel             -- waar komt het vandaan?
WHERE    voorwaarde        -- welke rijen?
GROUP BY kolom             -- samenvatten per groep
ORDER BY kolom            -- sorteren
LIMIT    aantal;           -- hoeveel rijen?

2. Rijen filteren: WHERE en NULL

Welke reparaties zijn nog niet klaar? Bij een lopende reparatie is datum_klaar leeg: in SQL heet dat NULL. Op NULL controleer je met IS NULL, niet met = NULL.

SELECT reparatie_id, omschrijving, status, datum_beloofd
FROM reparatie
WHERE datum_klaar IS NULL
ORDER BY datum_beloofd, reparatie_id
LIMIT 5;

4. Rekenen: doorlooptijd en te laat

DATEDIFF(a, b) geeft het aantal dagen tussen twee datums. De vergelijking datum_klaar > datum_beloofd geeft 1 (waar) of 0 (niet waar), dus het gemiddelde daarvan is het aandeel reparaties dat te laat was.

SELECT COUNT(*)                                            AS aantal,
       ROUND(AVG(DATEDIFF(datum_klaar, datum_binnen)), 1)  AS gem_doorlooptijd,
       ROUND(AVG(datum_klaar > datum_beloofd) * 100)       AS pct_te_laat
FROM reparatie
WHERE datum_klaar IS NOT NULL;

Resultaat

10766.238

5. Tabellen koppelen: JOIN

Of een fiets een e-bike is, staat niet in reparatie maar in fiets. Met een JOIN koppel je de tabellen via de sleutel fiets_id. De letters r en f zijn afkortingen (aliassen) voor de tabelnamen.

SELECT f.is_ebike,
       COUNT(*)                                     AS aantal,
       ROUND(AVG(r.datum_klaar > r.datum_beloofd) * 100) AS pct_te_laat
FROM reparatie r
JOIN fiets f ON f.fiets_id = r.fiets_id
WHERE r.datum_klaar IS NOT NULL
GROUP BY f.is_ebike;

Resultaat

is_ebikeaantalpct_te_laat
048820
158853

is_ebike = 1 betekent e-bike. E-bikes zijn ruim 2,5 keer zo vaak te laat als gewone fietsen.

6. De kernvraag: wachten op onderdelen

Een reparatie heeft "op een onderdeel gewacht" als er in reparatie_onderdeel een regel is met een besteld_op-datum. Dat controleer je met EXISTS en een subquery: een query binnen een query. CASE maakt er een leesbaar label van.

SELECT CASE
         WHEN EXISTS (SELECT 1
                      FROM reparatie_onderdeel ro
                      WHERE ro.reparatie_id = r.reparatie_id
                        AND ro.besteld_op IS NOT NULL)
         THEN 'besteld'
         ELSE 'op voorraad'
       END                                                AS onderdeel,
       COUNT(*)                                           AS aantal,
       ROUND(AVG(DATEDIFF(datum_klaar, datum_binnen)), 1) AS gem_doorlooptijd,
       ROUND(AVG(datum_klaar > datum_beloofd) * 100)      AS pct_te_laat
FROM reparatie r
WHERE datum_klaar IS NOT NULL
GROUP BY onderdeel;

Resultaat

onderdeelaantalgem_doorlooptijdpct_te_laat
besteld44410.768
op voorraad6323.117

Dit is de onderbouwing van de grondoorzaak uit de probleemanalyse: als er een onderdeel besteld moet worden, duurt een reparatie ruim drie keer zo lang en is die in twee derde van de gevallen te laat.

7. Welke onderdelen zorgen voor vertraging?

SELECT o.naam,
       COUNT(*)                                               AS keer_besteld,
       ROUND(AVG(DATEDIFF(ro.geleverd_op, ro.besteld_op)), 1) AS gem_levertijd
FROM reparatie_onderdeel ro
JOIN onderdeel o ON o.onderdeel_id = ro.onderdeel_id
WHERE ro.besteld_op IS NOT NULL
GROUP BY o.naam
ORDER BY keer_besteld DESC
LIMIT 5;

Zelf proberen

✏️ Opdracht 1

Hoeveel klanten hebben meer dan één fiets? Tip: gebruik GROUP BY met HAVING; dat is een WHERE voor groepen.

Bekijk het antwoord
SELECT COUNT(*) AS klanten_met_meer_fietsen
FROM (SELECT klant_id
      FROM fiets
      GROUP BY klant_id
      HAVING COUNT(*) > 1) AS x;
klanten_met_meer_fietsen
133

De binnenste query geeft alle klanten met meer dan één fiets; de buitenste telt ze.

Welke monteur heeft de langste gemiddelde doorlooptijd? En is dat eerlijk? Kijk ook naar het aandeel e-bikes per monteur.

Bekijk het antwoord
SELECT m.naam,
       COUNT(*)                                             AS reparaties,
       ROUND(AVG(DATEDIFF(r.datum_klaar, r.datum_binnen)), 1) AS gem_doorlooptijd,
       ROUND(AVG(f.is_ebike) * 100)                          AS pct_ebike
FROM reparatie r
JOIN monteur m ON m.monteur_id = r.monteur_id
JOIN fiets f   ON f.fiets_id = r.fiets_id
WHERE r.datum_klaar IS NOT NULL
GROUP BY m.naam
ORDER BY gem_doorlooptijd DESC;
