# courses

Statische websites met lesmateriaal per course. Geen build-stap nodig: Vercel publiceert de map zoals hij is.

- `index.html`: overzicht van alle courses
- `assets/style.css`: gedeelde opmaak
- `startsemester/process-data-in-organisations/`: Startsemester, topic Process Data in Organisations (16021)

Nieuwe course toevoegen: maak een nieuwe map (bijv. `startsemester/andere-topic/`), gebruik dezelfde stylesheet (`../../assets/style.css`) en zet een kaart erbij in `index.html`.

Lokaal bekijken: open `index.html` in je browser.
